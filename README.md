# DummyJSON REST API Testing

## Overview
A hands-on REST API testing project using Postman and the DummyJSON API.
https://github.com/Abdelsabour99/dummyjson-api-testing-postman/blob/main/README.md
## Tools & Technologies
- Postman
- REST APIs
- JSON
- API Testing

## Scope
The project focuses on testing Product API endpoints using:
- GET
- POST
- PUT
- DELETE

## Testing Activities
- Test case design and execution
- Positive and negative testing
- Status code validation
- Response data validation
- JSON/schema validation
- Response time validation
- Postman automated assertions

## Test Cases
The project includes test scenarios for:
- Creating a product
- Retrieving a product
- Retrieving a non-existent product
- Updating a product
- Deleting a product
- Validating the behavior after deletion
